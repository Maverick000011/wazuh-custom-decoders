# Wazuh Custom Decoders

This repository contains custom **Wazuh decoders** developed to parse and normalize logs from different network security devices and firewalls.

The purpose of these decoders is to improve log parsing, field extraction, event identification, and security monitoring within Wazuh.

## Supported Devices

Currently, this repository includes custom decoders for:

* **Huawei Firewall**
* **Sangfor Firewall**

## Repository Structure

```text
wazuh-custom-decoders/
│
├── Huawei1_Decoder.xml
├── Huawei2_Decoder.xml
├── sangfor-fw.xml
└── README.md
```

## Decoders

### Huawei Decoders

#### `Huawei1_Decoder.xml`

Custom Wazuh decoder for parsing Huawei firewall logs and extracting relevant event information.

#### `Huawei2_Decoder.xml`

Additional Huawei firewall decoder designed to handle specific Huawei log formats and event fields.

### Sangfor Firewall

#### `sangfor-fw.xml`

Custom Wazuh decoder for parsing Sangfor firewall logs and identifying relevant security events and fields.

## Installation

Copy the required decoder XML file(s) to the Wazuh Manager decoder directory:

```bash
/var/ossec/etc/decoders/
```

For example:

```bash
sudo cp Huawei1_Decoder.xml /var/ossec/etc/decoders/
sudo cp Huawei2_Decoder.xml /var/ossec/etc/decoders/
sudo cp sangfor-fw.xml /var/ossec/etc/decoders/
```

After adding or modifying the decoders, restart the Wazuh Manager:

```bash
sudo systemctl restart wazuh-manager
```

Verify that the Wazuh Manager is running:

```bash
sudo systemctl status wazuh-manager
```

## Testing the Decoders

Wazuh provides the `wazuh-logtest` utility to test custom decoders and rules.

Run:

```bash
/var/ossec/bin/wazuh-logtest
```

Paste the raw firewall log into the tool and verify the following stages:

```text
Phase 1: Completed pre-decoding.
Phase 2: Completed decoding.
Phase 3: Completed filtering (rules).
```

The decoded fields should match the expected values from the firewall log.

## Customization

The decoders can be modified according to the log format received from the respective devices.

When modifying a decoder, make sure to:

1. Validate the XML syntax.
2. Test the decoder using `wazuh-logtest`.
3. Verify that the expected fields are extracted.
4. Confirm that the appropriate Wazuh rules are triggered.
5. Restart the Wazuh Manager after applying the changes.

## Notes

These are **custom/community-developed decoders** and may require modification depending on:

* Firewall model
* Firmware/software version
* Syslog format
* Log type
* Vendor-specific fields
* Configuration of the sending device

Always test the decoder against your actual log samples before deploying it in a production environment.
